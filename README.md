## Key Features
- **100% Offline Audio**: Zero cloud dependencies, zero telemetry, and zero phone-home tracking.
- **10-Band Graphic Equalizer**: Hardware simulated parametric DSP with curve interpolation (-12dB to +12dB).
- **Interactive Visualizer**: 60 FPS real-time audio canvas spectrum analyzer.
- **Discover & Flow**: Mood pills (Chill, Lofi, Workout, Focus), local catalog indexing, and smart playlists.
- **Dual Themes**: Deep Space Dark & Pearlescent Light mode with instantaneous toggle.
- **Release Auto-Sync**: Automatically synchronizes and links latest releases from GitHub Releases API.
